# Iconos del menú

Estos SVG proceden del set **Tabler Icons**, descargados desde la API de Iconify (`https://api.iconify.design/tabler/{icon}.svg`). Se usan localmente para que el sistema siga funcionando sin conexión. Todos se renderizan con la misma cuadrícula de 24 px, trazo de 2 px y el verde del sistema `#527a63`.

Tabler Icons se distribuye bajo licencia MIT. Se conserva el texto de la licencia en `TABLER-LICENSE.txt`.

Se revisó el catálogo de comida de [Flaticon](https://www.flaticon.es/iconos-gratis/comida) como referencia de estilos y descarga; no se copiaron iconos premium ni se dejó una dependencia de red en la aplicación. Si el restaurante solicita una colección de Flaticon, se debe guardar la licencia/atribución del pack elegido antes de reemplazar estos SVG.
