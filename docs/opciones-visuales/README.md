# Previsualizaciones visuales

Estas cuatro variantes se cargan únicamente cuando se agrega `?visual=opcionN` a la URL. La aplicación sin ese parámetro conserva el estilo actual.

- `opcion1`: Verde bosque suave. Ajuste recomendado, conserva la identidad actual y mejora estados, foco y profundidad.
- `opcion2`: Dorado artesanal. Refuerza la relación con el horno de leña y usa acentos cálidos.
- `opcion3`: Crema editorial. Usa más espacio, menos sombras y una composición más sobria.
- `opcion4`: Operación de alto contraste. Hace más visibles estados, bordes y acciones para horas de alta demanda.

Cada carpeta contiene el CSS de previsualización y las capturas generadas:

- `dashboard.png`: resumen del sistema.
- `pedido.png`: captura de pedido con mesas, carta e iconos.
- `hamburguesa.png`: configuración de ingredientes y notas.
- `bebidas.png`: categorías de bebidas y configuración.

La opción activa sigue siendo el estilo base de `src/ui/styles.css` hasta que se seleccione una variante.
